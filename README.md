# Mobile Phone Sales Analysis | Power BI

## Project Overview

This project presents an interactive Power BI dashboard for analyzing mobile phone sales performance. It explores sales revenue, units sold, transactions, customer ratings, brand performance, and sales trends across months, days of the week, and cities.

The dashboard helps users identify top-performing mobile models, compare brands, and understand sales patterns through interactive filters and visualizations.

## Key Dashboard Features

- KPI cards for total sales, total quantity, transactions, and average price
- Sales comparison across mobile phone models
- Monthly quantity and sales trend analysis
- Sales comparison by day of the week
- Customer rating distribution
- Brand-level comparison of sales, quantity, and transactions
- City-level sales visualization
- Interactive slicers for mobile model, payment method, brand, day name, and month

## Key Insights

- **Top-performing model:** iPhone SE recorded the highest sales among the models analyzed.
- **iPhone SE monthly performance:** January had the highest number of iPhone SE units sold.
- **Overall monthly performance:** July recorded the highest total sales across all phone models.

*These findings should be verified against the dataset and the relevant measures before publication.*
